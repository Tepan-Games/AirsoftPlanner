## Nouveautés
- **Logiciel libre** : Airsoft Planner est publié sous licence GNU GPL v3.0 (fichier LICENSE joint au package et installé avec le logiciel).
- **Application Android signée avec la clé de publication du projet** : les mises à jour suivantes s'installeront directement par-dessus.

## Important pour les téléphones
L'application 0.9.0 avait été signée avec une clé de développement. Pour passer en 0.9.1, **désinstallez une fois l'application 0.9.0**, puis installez `AirsoftPlanner-0.9.1.apk` et enrôlez de nouveau le téléphone (code d'équipe ou QR code). Les versions suivantes se mettront à jour normalement.

## Téléchargements
- **AirsoftPlanner-0.9.1.zip** : package complet (installateur Windows, application Android, guide d'utilisation PDF, OP d'exemple, licence).
- **AirsoftPlanner-0.9.1-Setup.exe** : installateur Windows seul. Le logiciel 0.9.0 installé le propose aussi en mise à jour.
- **AirsoftPlanner-0.9.1.apk** : application Android.

Si Windows affiche « Windows a protégé votre ordinateur » : « Informations complémentaires » puis « Exécuter quand même » (l'installateur n'est pas encore signé).
