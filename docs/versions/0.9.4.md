## Version bêta ouverte
- **Donner mon avis** : menu « ⋯ » du logiciel ou bouton en bas de l'application. Formulaire rapide, sans inscription ; la version, la plateforme et la langue sont jointes automatiquement. Avec un compte GitHub, des modèles « Signaler un problème » et « Proposer une idée » sont aussi proposés.
- **Soutenir le projet** : menu « ⋯ » ou bouton de l'application, vers la page Ko-fi (don ponctuel, facultatif). Le logiciel reste gratuit et libre.
- **À propos** complété : version bêta, licence GPL, confidentialité, crédits des cartes.
- Guide d'utilisation : nouvelle section « Version bêta : donner son avis, soutenir le projet ».

## Téléchargements
- **AirsoftPlanner-0.9.4.zip** : package complet (installateur Windows, application Android, guide d'utilisation PDF, OP d'exemple, licence).
- **AirsoftPlanner-0.9.4-Setup.exe** : installateur Windows seul. Le logiciel installé le propose aussi en mise à jour au démarrage.
- **AirsoftPlanner-0.9.4.apk** : application Android (s'installe par-dessus la version précédente).

Les fichiers d'OP de la version 0.9.3 s'ouvrent sans changement.

Si Windows affiche « Windows a protégé votre ordinateur » : « Informations complémentaires » puis « Exécuter quand même » (l'installateur n'est pas encore signé).
